# am_diffusion_2d
2D diffusion equation solver with visualization in MATLAB
# 2D Diffusion Equation Solver

## Equation

The 2D diffusion equation solved by this code is:

$$
\frac{\partial u}{\partial t} = D \left( \frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2} \right)
$$

where:
- \( u(x, y, t) \) is the scalar quantity (e.g., temperature) being diffused,
- \( D \) is the diffusion coefficient (assumed constant),
- \( x, y \) are the spatial coordinates,
- \( t \) is time.
